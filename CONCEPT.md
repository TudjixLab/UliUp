# Концепция Uli Up / Uli UpS

**Uli Up / Uli UpS** — самостоятельная платформа TudjixLab для подготовки и установки обновлений программных проектов без обязательного облачного сервиса.

## Uli Up — настольное приложение

Приложение для **Windows и Linux**, через которое разработчик:
- выбирает папку подготовленного проекта и создаёт пакет обновления `.uli4`;
- хранит список подключений к своим серверам и проектам;
- выбирает готовый пакет, отправляет его в нужный проект и отслеживает результат;
- получает сведения об ошибках установки и повторяет отправку исправленного обновления.

Интерфейс планируется на русском и английском языках. Приложение уведомляет о доступных собственных обновлениях.

## Uli UpS — компонент проекта

Серверная часть, которую разработчик **при желании устанавливает внутрь конкретного проекта** на Linux-сервере, в том числе в Docker-окружении.

Uli UpS автономно:
- принимает обновления от Uli Up;
- обновляет файлы проекта и при необходимости самого себя;
- выполняет предусмотренные проектом сборку, запуск и проверку работы;
- обеспечивает автозапуск и передаёт результаты и ошибки в Uli Up;
- при неудачной установке восстанавливает прежнее рабочее состояние, когда это технически возможно.

## Как это работает

**Разработчик готовит и проверяет проект → Uli Up упаковывает его в `.uli4` → разработчик выбирает подключение → Uli UpS применяет обновление → Uli Up показывает результат.**

После первоначальной установки Uli UpS штатные обновления выполняются удалённо, без ручной работы на сервере.
