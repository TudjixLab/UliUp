# Uli Up / Uli UpS

**Uli Up / Uli UpS** — разрабатываемая TudjixLab программная платформа для подготовки, выпуска и управления обновлениями программного обеспечения.

Проект создаётся как самостоятельный инструмент для разработчиков.

## Статус проекта

**В разработке — этап проектирования.**

Краткий ход работ: [Дорожная карта](ROADMAP.md).
